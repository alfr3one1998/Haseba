# تطبيق حاسبة الكيك

تطبيق أندرويد يعمل بدون إنترنت ويضم الحاسبة داخل ملف APK. يحافظ على معادلات وأسعار الموقع، مع حركة تدريجية للأرقام وتأثير ضغط الأزرار وظهور النتائج وتنقل سلس، ودعم تقليل الحركة من إعدادات الجهاز.

- أندرويد 8 أو أحدث.
- لا يحتاج صلاحيات إنترنت أو ملفات.
- المصدر: app/src/main/assets/index.html

## تنزيل النسخة التجريبية

افتح Actions في المستودع، ثم آخر تشغيل ناجح باسم Build Android APK. من Artifacts نزّل Haseba-Android-APK وفك ملف ZIP وثبّت app-debug.apk على الهاتف.

هذه نسخة APK تجريبية موقعة بمفتاح debug؛ ليست إصدار Google Play. يلزم مفتاح توقيع ثابت للإصدارات النهائية والتحديثات المستمرة.

## البناء محلياً

يتطلب JDK 17 وAndroid SDK 35 وGradle 8.11.1. من مجلد android شغّل:

```sh
gradle assembleDebug
```

الملف الناتج: app/build/outputs/apk/debug/app-debug.apk
