# حاسبة الكيك — أندرويد 2.0

تطبيق محلي يعمل دون إنترنت على أندرويد 8 فأحدث.

## الخصائص

- السعر من المقاس، المقاس من الميزانية، والمقاس من عدد الأشخاص.
- حصص صغيرة ومتوسطة وكبيرة قابلة لتعديل الأسماء والمقاسات.
- رسم الكيكة والتقطيع وحركة الأرقام والنتائج والأزرار.
- إضافات وخصومات قابلة للتعديل؛ أسعار الإضافات الأولية صفر حتى ضبطها.
- حفظ حسابات باسم العميل والعربون والمتبقي وموعد الاستلام والملاحظات والبحث والحذف.
- صورة عرض سعر ومشاركة Android كنص أو صورة مع اختيار واتساب أو غيره؛ لا يرسل التطبيق تلقائياً.
- الحساب المحفوظ يحتفظ بقيمته وقت الحفظ، ونسخه للحاسبة يعيد تسعيره بالأسعار الحالية.

## الإعدادات

طرق التسعير: تدرج أسعار المساحات المرجعية، نسبة مساحة كيكة أساسية، عدد الكيكات الكاملة مع تدوير الكيكة الأساسية لتقليل العدد، أو تكلفة تركيبة كيكة أساسية مع التشغيل وهامش على التكلفة. المقاسات المرجعية تحتاج مساحات وأسعاراً متزايدة دون تكرار. تقريب السعر اختياري، والإضافات السالبة خصم.

التركيبة: أسماء المكونات وكمياتها ووحداتها وتكلفة كل وحدة للكيكة الأساسية. لا يوجد مخزون أو قاعدة بيانات سحابية. جميع الإعدادات والحسابات محفوظة محلياً؛ مسح بيانات التطبيق أو حذفه يمسحها.

## تنزيل APK

Actions → آخر تشغيل ناجح Build Android APK → Haseba-Android-APK. فك ZIP وثبّت app-debug.apk. هذه نسخة تجريبية؛ لم تُختبر على جهاز فعلي وليست إصدار Google Play.

مفتاح توقيع النسخ التجريبية مخزن في GitHub Actions cache بعد الإصدار 2.0. قد يحتاج الانتقال من الإصدار 1.0 إلى إزالة النسخة الأولى مرة واحدة بسبب اختلاف التوقيع. استمرار التحديثات مضمون فقط عند بقاء المفتاح؛ النشر النهائي يحتاج مفتاح توقيع ثابت محفوظ بأمان.

## البناء

JDK 17، SDK 35، Gradle 8.11.1. داخل android:

```sh
gradle assembleDebug
```

الملف الناتج app/build/outputs/apk/debug/app-debug.apk.
