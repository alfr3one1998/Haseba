# حاسبة مقاسات الكيك

نسخة من الحاسبة الحالية، بنفس التصميم والأسعار وحساب الأشخاص واقتراح المقاس من الميزانية.

الموقع ثابت ويعمل باستخدام HTML وCSS وJavaScript دون خادم أو قاعدة بيانات.

## تشغيل GitHub Pages

1. افتح Settings ثم Pages.
2. اختر Deploy from a branch.
3. اختر main ثم / (root) واضغط Save.
4. بعد اكتمال النشر سيكون الرابط: https://alfr3one1998.github.io/Haseba/

للتشغيل محليًا افتح index.html في المتصفح.
